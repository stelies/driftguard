What it does

🧭 Drift guard

A managed block in your global rules: a project registry plus protocols. Stop and poll when you drift, gate new projects ("which active project pauses?"), and calm down when you're frustrated.

📌 Purpose blocks

Each project's CLAUDE.md / AGENTS.md / GEMINI.md / .cursor/rules gets its purpose, done-condition and the drift traps you actually fell into, with dates.

🎤 Interview

Your agent polls you about goals, plan, tone and "is this verdict fair?". Your answers override the AI.

🧠 Brain-disconnect map

Focus decay by prompt position, an hour × weekday heatmap, and per-session strips that show where you zone out.

🪫 Token crisis mode

Detects heavy usage and goes frugal. driftguard handoff writes a ≤40-line HANDOFF.md so you can restart cheap.

🔁 Pulse

An opt-in SessionStart hook that checks new sessions for zero tokens and stays silent unless something needs you.

How it works

  1. 1 · 0 tokens
    Scan

    Reads every agent's local history, incrementally, then picks a mode: new user → more diagnostics; heavy usage → frugal.

  2. 2 · your agent
    Score digests

    Cheap subagents read prompt-only digests (often 100× smaller than transcripts) and score sessions and projects.

  3. 3 · you
    Interview

    Polls about goals, limits and verdicts. Your answers win over the AI.

  4. 4 · 0 tokens
    Report + guard

    An interactive report on localhost; guard blocks are shown as a diff and applied only after you agree.
